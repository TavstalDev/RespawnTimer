## Description
RespawnTimer is a Minecraft mod that punishes players with different respawn timers based on their death causes.

## Features
- Customizable respawn times for various death causes.
- Easy configuration through `config.yml`.
- Supports multiple languages.
- Automatic update notifications.

## Installation

1. Download the latest release from the [releases page](https://github.com/TavstalDev/RespawnTimer/releases/latest).
2. Place the downloaded `.jar` file into your server's `plugins` directory.
3. Restart your server to generate the configuration files.
